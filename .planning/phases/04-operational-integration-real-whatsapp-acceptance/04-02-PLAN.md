# Phase 4 Plan 02: One-number WhatsApp Self-Chat

**Goal:** Let the linked WhatsApp account send prompts to itself while ignoring only messages emitted by the gateway, so one number can operate Claude and Codex through `/init`, `/claude`, and `/codex`.

**Architecture:** Add an explicit opt-in configuration flag to the existing WhatsApp translator and channel. Self-sent messages remain subject to the existing allowlist; outbound message IDs returned by Baileys are tracked briefly and skipped on echo. The gateway accepts an explicit route override for command-selected Claude/Codex turns. Default behavior remains fail-closed for deployments that do not enable the flag.

**Verification:** Focused translation/channel tests, full `npm test`, `npm run doctor`, `graphify update .`, and a restarted gateway with the one-number flag enabled.
